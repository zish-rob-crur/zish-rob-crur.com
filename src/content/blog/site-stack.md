description: 'A short note on the current setup: Astro, GitHub, Cloudflare Pages, and a writer-first default.'
pubDate: '2026-03-19'
---

The site is intentionally simple.

It is built with Astro, stored on GitHub, and deployed on Cloudflare Pages. That stack keeps the
workflow light:

- Write locally
- Push to GitHub
- Let Cloudflare build and ship

That is enough for now.

I do not need a large CMS before I have the writing. I do not need a complicated frontend before I
have a clear tone. The infrastructure can stay modest while the archive becomes more real.

As the site grows, the design can keep evolving. The baseline should still be the same: readable,
stable, and low-noise.
